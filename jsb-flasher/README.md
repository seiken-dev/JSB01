# JSB01 Firmware Flasher

JSB01のファームウェア書き込みツールです。
USBシリアル接続されたJSB01を自動的に検出し、BOOTSELモードへリセットしてから `.uf2` ファームウェアを書き込みます。

## 特徴

* **自動リセット**: 1200bps シリアル通信によるリセット（"1200bps touch"）を行い、BOOTSELボタンを押さなくてもマスストレージモードに移行させます。
* **自動書き込み**: マウントされたRPI-RP2ドライブを自動検出し、ファームウェアをコピーします。
* **配布用ビルド**: PyInstallerを使用して、単一の実行ファイル(`.exe`)として配布可能です。

## 必要要件

* Windows
* Go 1.25 以上
* Task

## ビルド

``` bash
task build
```

## 使い方

### 開発時の実行

ファームウェアファイルを引数として指定して実行します。

```bash
go run main.go ./firmware.uf2
```

複数のRP2040が接続されていると書き込みを行いません。-pオプションでポート名を指定してください。

```bash
go run main.go -p COM10 ./firmware.uf2
```

### 配布ファイルの実行

引数なしで実行されます。ファームウェアファイルが指定されなかった場合には、実行ファイルと同じ場所にあるfirmware.uf2が書き込まれます。このファイルは正しいものであるかが検査されます。複数のRP2040
が検出されたときには-pオプションを指定してください。

### 配布用実行ファイル (EXE) の作成

他のPCで実行するための単一実行ファイルを作成します。

```bash
task build
```

`jsb01-firmware/ｊｓｂ01-flasher.exe` が生成されます。
この `exe` ファイルと `firmware.uf2` を同じフォルダに置き、`exe` を実行するだけで書き込みが完了します。

## 仕組み

1. Vid/Pid (0x2E8A:0x0005) を持つシリアルポート（CircuitPython/MicroPython等で動作中）を探します。
2. 見つかったポートを **1200bps** でオープン/クローズし、リセットをトリガーします。
3. `RPI-RP2` ボリュームがマウントされるのを待機します。
4. `.uf2` ファイルをボリュームにコピーします。
   * コピー完了後、Picoは自動的に再起動してファームウェアを実行します。

## 設定

`jsb01_flasher.py` 内の定数で以下の挙動を変更できます。

* `EXPECTED_HASH`: ハッシュ検証を行う場合の期待値
* `PICO_VID` / `PICO_PID`: ターゲットデバイスの識別子
