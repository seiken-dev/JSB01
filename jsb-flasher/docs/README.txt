JSB01 ファームウェアアップデート手順

このフォルダには、JSB01のファームウェア更新ツールと最新のファームウェアファイルが含まれています。
以下の手順に従ってアップデートを行ってください。

1. JSB01本体の接続
   JSB01本体をUSBケーブルでパソコンに接続してください。

2. ファイルの展開
   ダウンロードした圧縮ファイル（.zip）をまだ展開していない場合は、ファイルを右クリックして「すべて展開」を選択し、フォルダを展開してください。
   ※圧縮（zip）フォルダの中にある実行ファイルを直接開いても正常に動作しません。必ず展開してから実行してください。

3. アップデートの実行
   展開したフォルダ内にある実行ファイル「jsb01-flasher.exe」（環境によっては「jsb01-flasher」と表示されます）をダブルクリックして開いてください。

4. アップデートの完了
   自動的にファームウェアの書き込みが始まります。
   書き込みが完了すると、JSB01本体が自動的に再起動します。これにてアップデートは完了です。
